# PNGs dos devices MikroTik

Coloque aqui os arquivos `.png` (um por modelo), nomeados pelo **board** do RouterOS.
Ex.: `L009UiGS-2HaxD.png`, `CCR1009-7G-1C-1Splus.png`, `hex_s.png`, `RB750Gr3.png`.

O nome é normalizado (minúsculas, sem símbolos, `+`→`plus`), então variações de
caixa/underscore/hífen e sufixos `-IN`/`_rm` são toleradas. Sem correspondência,
o device cai no desenho sintético.
